# Ruthwik Goparaju Portfolio

Professional biomedical engineering portfolio built with Vite and vanilla JavaScript.

## Featured project sources

- MedAxis 3D: https://github.com/ruthwikg-create/MedAxis-3D
- BioSimulX: https://github.com/ruthwikg-create/biosimulx
- PulmoAcoustic: https://github.com/ruthwikg-create/PulmoAcoustic
- PhonoCardio: https://github.com/ruthwikg-create/PhonoCardio
- NeuroVision AI: https://github.com/RuthwikGoparaju/NeuroVision-AI

## Stack

- Vite
- JavaScript
- CSS
- Canvas 2D

## Run locally

```bash
npm install
npm run dev
```

## Notes

The portfolio describes each project from its repository documentation where available. Project links open the corresponding GitHub repository in a new tab.

The hero and contact use dense Canvas 2D galaxy fields. Particles orbit through layered spiral arms, respond to depth and twinkle, then repel the cursor with increasing force as it approaches, creating a same-pole magnetic effect. Canva and Microsoft Word are part of the same scrolling tools marquee and are marked PRO.

No em dash punctuation is used in this portfolio.
